# Origine dei loghi

Tailscale, Syncthing, Proton VPN, LocalSend: SVG Simple Icons (CC0), https://github.com/simple-icons/simple-icons/tree/develop/icons.
Slack: https://github.com/simple-icons/simple-icons/blob/14.0.0/icons/slack.svg (CC0).
Obsidian: https://github.com/simple-icons/simple-icons/blob/14.0.0/icons/obsidian.svg (CC0).
Pi: https://pi.dev/logo-auto.svg, reso monocromatico.
T3: vector reconstruction of the monogram from the icon installed at /opt/t3code-bin/usr/share/icons/hicolor/128x128/apps/t3code.png.
Octo: monochrome SVG reconstruction of the user-provided octo-agente-pfp.jpeg image, with transparent eyes and a simplified silhouette for the 16 px size.
VM: simbolo vettoriale monitor disegnato localmente.
Anki: original locally drawn star-on-card SVG, not an upstream Anki logo. The installed application icon is raster; these 16 px monochrome variants match the dock palette.

The -active and -inactive variants differ only in color; the -source files are kept for regenerating them.
